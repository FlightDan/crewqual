# 产品概览

[Wiki 目录](../README.md) · [English](../en/overview.md) · [技术文档](../../docs/zh-CN/README.md)

CrewQual 用于管理成员资质、证件有效期、更新申请和人工审核，也包含日历、通知和升级计划。成员通过门户查看自己的资质并提交凭证；管理员维护人员与规则、审核更新、跟进临期事项。

## 基本概念

| 名称       | 含义                                                                       |
| ---------- | -------------------------------------------------------------------------- |
| 成员       | 组织内的人员档案，包含员工号、联系方式、所属单位和任职信息。               |
| 职位与任职 | 职位规定需要哪些资质；成员档案记录主职和兼任。                             |
| 资质要求   | 指定职位所需的资质，以及对应的有效期和字段规则。                           |
| 正式记录   | 当前生效的资质数据，用于显示有效期和资质状态。                             |
| 更新申请   | 成员上传凭证、填写字段后形成的待审核材料。提交成功不表示正式记录已经更新。 |
| 人工审核   | 有权限的管理员核对凭证、纠正字段，并决定通过或退回。                       |
| 升级计划   | 将人员的晋升或训练安排分为阶段，跟踪计划与阶段进度。                       |

成员管理按职位提供入口。仓库也保留 `/pilot` 飞行员门户和相关页面；通用成员门户位于 `/member`。

## 一次资质更新如何完成

1. 成员打开资质，上传证件图片并核对字段。
2. 如已配置 AI 服务，系统提供识别或比对结果；成员仍可手工填写。
3. 成员提交申请，系统生成回执。
4. 管理员在待审核页面比较凭证、提交内容、辅助识别结果与正式记录。
5. 管理员通过申请后，新的资质记录生效；退回时，成员按意见补充材料后重新提交。

AI 结果用于辅助录入和审核。系统不会因为 AI 判断通过就自动批准申请。

## 有效期与提交状态

有效期规则包括手工填写到期日、根据签发日或训练日计算固定月数，以及长期有效。长期有效的资质不填写到期日。固定周期资质的日期需要符合配置规则。

成员页面按已过期、30 天内到期、90 天内到期和正常资质分组。提交回执单独显示已接收、审核处理中、审核通过或需要补充材料。查看资质是否更新时，应同时检查申请结果和正式记录。
