## 登录与权限

访问 `/admin/login`，输入管理员邮箱，并按登录页面要求填写密码、动态验证码（TOTP），或两者。实际登录方式由安全策略决定。

| 角色                     | 常见操作                                                                         |
| ------------------------ | -------------------------------------------------------------------------------- |
| 超级管理员 `SUPER_ADMIN` | 全部管理权限，包括管理员账户、安全策略、备份恢复、系统更新和审计。               |
| 管理员 `ADMIN`           | 维护人员、审核申请、管理日历和升级计划、重试通知，以及维护单位、职位和通知设置。 |
| 审核员 `REVIEWER`        | 查看人员和业务页面，并通过或退回申请。                                           |
| 查看者 `VIEWER`          | 查看业务页面，无审核决定和业务写入权限。                                         |

非超级管理员必须分配所属单位，人员数据按单位范围访问。能打开设置页面不表示能修改其中所有设置。系统至少需要保留一名启用的超级管理员。

## 整理成员与资质要求

1. 在系统设置中检查组织、单位和职位配置。成员管理首页按已安装的职位模板展示入口。
2. 进入成员管理，选择职位，再查找或新增成员。有批量导入需求时，使用页面的 CSV 导入和预览流程，先处理预览中报告的错误。
3. 核对员工号、登记手机号、所属单位和启用状态。这些信息影响成员访问门户。
4. 在成员详情核对主职、兼任、职位要求和正式资质记录。
5. 在资质配置页面检查资质名称、有效期规则和字段限制，再让成员按规则提交更新。

## 审核更新申请

打开 `/admin/reviews`，选择待审核申请。

1. 查看凭证图片，核对提交字段、AI 辅助结果和当前正式记录。
2. 字段有误时使用人工纠正。原提交值保留在审核记录中，纠正后的字段标记为人工修正。
3. 材料满足要求时，选择通过，确认已核对凭证和信息；审核备注可选填。
4. 需要补充材料时，选择退回修改，填写具体原因，例如“请补传包含到期日期的证件下半页”。退回原因至少 5 个字符。
5. 检查审核结果和通知状态。外部通知按已配置的渠道发送。

若提示记录已被其他人修改，请重新加载申请并核对最新内容后再决定。

部分人员资质维护页面还允许有权限的管理员直接修正正式记录。保存会立即更新资质并写入审计记录，操作前应核实凭证和日期。

## 日常跟进

仪表盘和成员列表用于定位缺失、过期或临期的资质。日历集中展示相关事项；升级计划页面用于维护阶段安排和进度。

通知日志用于查看发送状态，具备重试权限的管理员可重试适用的失败通知。成员未收到短信时，先核对人员资料，再检查通知配置和日志。

AI、对象存储、媒体优化、安全、备份和更新等系统设置由相应权限控制。部署、升级、备份与恢复的具体操作见[技术文档](../../docs/zh-CN/README.md)。
