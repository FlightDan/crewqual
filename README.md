# CrewQual
CrewQual 是一款现代化可私有部署的人员资质与合规管理平台。
面向航空及其他需要持续管理证照、培训、有效期与晋级计划的组织。
它将人员资质、到期预警、材料提交、辅助校验、人工审核和升级计划整合到统一、可追踪、可审计的工作流中。

## 功能

- **成员门户**：成员可通过移动端查看个人资质、有效期和预警信息，并上传凭证或提交资质更新申请。
- **成员与岗位管理**：维护人员、组织及岗位关系，并根据岗位配置不同的资质要求。
- **资质规则管理**：配置资质类型、有效周期、提醒规则及适用岗位。
- **审核工作台**：集中处理成员提交的资质更新，结合材料识别、规则校验和人工审核完成记录生效。
- **日历与预警**：统一展示即将到期的资质、计划检查和关键节点。
- **升级计划**：配置晋级目标、检查项目、时间窗口和阶段性任务。
- **通知中心**：针对资质到期、审核结果和计划节点发送可定义的通知。
- **安全与权限**：提供角色权限、访问控制及关键业务操作审计。
- **运维能力**：支持 Docker Compose 部署、健康检查、异步任务、对象存储及备份恢复。

## 为什么选择 CrewQual

- **围绕完整闭环设计**：从到期提醒、成员提交、材料识别到人工终审和记录生效，都在同一套系统中完成。
- **人工决策优先**：AI/OCR 用于减少录入和核对成本，最终审批始终由有权限的管理员确认。
- **适应不同岗位**：职位、资质要求、提醒规则和升级路径均可配置。
- **兼顾移动端与桌面端**：成员门户面向手机使用，管理后台同时适配桌面与移动场景。
- **支持私有部署**：业务数据保存在 PostgreSQL，证照图片进入私有 S3 兼容存储，可部署在企业自有环境。
- **可审计、可恢复**：关键操作保留审计记录，并提供异步任务、健康检查和备份恢复能力。

## CrewQual 与多维表格的区别
CrewQual 更适合将资质合规作为长期、关键业务进行系统化管理。

- 开箱即用的业务模型：内置人员、职位、资质、有效期、审核记录与晋级计划，无需从零设计复杂表格。
- 完整的资质闭环：覆盖材料提交、AI 辅助核验、人工审核、记录生效、到期预警和通知。
- 更严格的业务约束：资质状态、规则版本、证据归属与审核权限由系统统一执行，减少误改、漏配和规则不一致。
- 面向不同角色的专属体验：成员通过移动端完成查询与提交，管理员通过工作台进行审核和风险管理，而不是共同操作一张复杂表格。
- 业务级审计能力：不仅记录“谁修改了哪个字段”，还记录审核决定、规则依据、证据材料和完整状态变化。
- 独立部署与数据控制：支持私有化部署，可自主控制数据库、证照文件、备份策略和外部服务集成。
- 支持深度定制：可以根据组织的职位体系、资质规则、晋级路径和审批制度进行代码级定制。

对于人员较少、规则简单、无需复杂审核和审计的场景，多维表格通常已经足够。
CrewQual 更适合资质管理逐渐成为长期、规范化业务流程的组织。

## 隐私/安全
CrewQual 设计为可自托管部署的软件。除非部署方主动配置外部服务或第三方集成，人员信息、资质记录、证书资料及其他业务数据均保存在部署组织自行控制的设施中。
CrewQual 可能处理包括姓名、员工号、联系方式、资质有效期、培训记录及证书图片等信息，因此建议部署方根据自身的数据安全、访问控制、备份及合规要求进行配置和管理。
AI 辅助核验为可选功能，并非 CrewQual 核心功能的必要依赖。启用 AI 或其他外部服务时，部署方应根据自身的数据处理政策、保密要求及适用法规选择合适的服务提供商，并确认相关数据的传输和处理方式符合组织内部要求。
CrewQual 本身不会在未经配置的情况下主动将业务数据发送至第三方服务。

如发现可能影响 CrewQual 安全性的漏洞，请不要通过公开 Issue 披露利用细节。
