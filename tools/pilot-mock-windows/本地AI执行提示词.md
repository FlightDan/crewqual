# 可直接交给本地 AI 的提示词

```text
你在一台完全离线、日志不外传的 Windows 计算机上处理飞行员假名化 mock 数据。

目标：
使用项目提供的 tools\pilot-mock-windows 转换工具，把“测试.xlsx”和唯一一个文件名含“通讯录”的 XLSX
转换为“CrewQual-飞行员批量导入-待补.csv”，然后按工具的验收规则检查结果。

隐私边界：
1. 不得输出、复述、截图或记录任何真实姓名、手机号、身份证、执照编号。
2. 不得要求用户把 CREWQUAL_MOCK_HMAC_KEY_HEX 粘贴到对话中，也不得读取、打印或保存该变量的值。
3. 不得生成真实人员与 mock 编号的明文对照表。
4. 不得修改“测试.xlsx”、通讯录或当前 CSV 模板。
5. 输出保留原始业务日期，只能称为“假名化 mock 数据”，不得称为匿名数据。

执行前检查：
1. 确认当前数据目录存在：
   - 测试.xlsx
   - 唯一一个文件名含“通讯录”的 .xlsx
   - CrewQual-飞行员批量导入模板-当前.csv
2. 仅检查 CREWQUAL_MOCK_HMAC_KEY_HEX 是否已设置；禁止显示其内容。
3. 如 Windows 隔离环境尚未安装，运行 tools\pilot-mock-windows\setup_windows.bat。

执行：
1. 在数据目录运行 tools\pilot-mock-windows\run_conversion.bat。
2. 输出文件已存在时先停止并请求用户确认；得到确认后才可添加 --overwrite。
3. 脚本报姓名或手机号匹配歧义时，只报告脚本给出的行号，不展示敏感单元格内容，不得降低校验强行继续。
4. 脚本报告某行某项资质整组留空时，保留该结果，不得猜测或手工补造日期、等级或颜色。

转换规则由脚本强制执行：
- 使用规范化姓名与真实手机号组成内部人员键，以秘密 HMAC-SHA-256 生成稳定 mock 员工号、姓名和测试手机号。
- 模拟机取上下半年较晚日期，到期日加 6 个月。
- 理论复训取上下半年较晚日期，到期日加 12 个月。
- 危险品以源签注日为起点，到期日加 24 个月。
- 体检以源签发日为起点；蓝色字体或填充为 6 个月，其他为 12 个月。
- 英语以 RELTA 为签发日，向后 3 年；汉语以“有效期”为到期日，向前 3 年。
- 当前六项外的资质、身份证和执照编号不进入目标 CSV。
- aircraftType、roleCode、unitCode、rankCode 保持空白，所以结果在人工补齐前不能正式导入。

验收：
1. 必须由脚本返回退出码 0 和“[完成]”结果。
2. CSV 必须为 UTF-8 BOM、CRLF，且第一行与当前模板的 31 列逐列一致。
3. 输出人数必须等于源表有效人员数；mock 员工号、姓名、手机号必须分别唯一。
4. 每个非空资质组必须有签发日、到期日和级别；模拟机、理论复训还必须有培训日。
5. 日期必须为 YYYY-MM-DD，到期日不得早于签发日。
6. 不得在输出中发现任何真实姓名、真实手机号、身份证或执照编号。
7. 同一输入与同一密钥重复转换应逐字节一致；密钥由用户本地保管，不参与提交验收。

最终只汇报：输出文件绝对路径、源表人数、手机号唯一匹配人数、六类资质写入数量、整组留空数量，
以及“该结果是假名化且基础必填字段尚未补齐”。不要在回复中引用任何源单元格内容。
```
