## 维护约定

中英文页面使用相同文件名，并在页首提供语言切换。修改命令、配置项或业务规则时，同步更新两种语言。文档中的命令应能在指定环境中执行；涉及数据修改时，写明前提和影响。

先核对代码，再写说明。保留界面上的术语，解释具体操作和结果，避免宣传用语。新增功能应在实现后写入操作指南，尚未实现的计划留在路线图中。
